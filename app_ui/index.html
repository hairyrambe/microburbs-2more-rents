Method, sources & limitations

Model: gradient boosting with recorded flat attributes, location, floor, block housing counts, earlier building and block rents, and prior rent history adjusted for market movement by a same-flat rent index. Historical features use earlier adverts only; bedrooms, bathrooms and parking on old adverts are never copied from the July input. Final data cutoff: 31 July 2026. Source: privately supplied Microburbs rental files; address identifiers use Open G-NAF, © Geoscape Australia, licensed by the Commonwealth with attribution and a mailing restriction.

The shown accuracy is a retrospective chronological result, not the organisers’ hidden judging result or a confidence interval for a particular flat. Prices are rounded to $0.50. Negative modelled parking premiums are set to zero by raising the with-parking prediction to the without-parking prediction. Missing attributes, unusual flats and unobserved building quality can reduce accuracy. Predictions represent advertised asking rents, not signed leases.

No API calls, external maps or analytics are used. Supplied records stay on this computer. Use the separate fictional demo mode for publicly shared recordings.
