# Rent explorer

See README.md for installation, data sources and method. START_RENT_APP.cmd uses private local input plus the new root rents_2more.csv. START_DEMO_APP.cmd uses fictional records only. The app never calls an API, uploads data or serves the private CSV files. Keep the terminal open while browsing.

Search by address, suburb or G-NAF ID; use the suburb filter for an exact area. Choose a flat and switch between with/without parking. The premium is an estimated scenario difference, not a causal valuation. Accuracy describes a separate retrospective check, not the chosen flat's confidence interval.
